# Security Policy

This project is a Markdown specification plus one small, dependency-free Node
script (`bin/check-decisions.mjs`). The attack surface is limited to that script.

## Reporting a vulnerability

Do not open a public issue for a security report.

Use GitHub's private vulnerability reporting:
https://github.com/dropout-developer/decisions.md/security/advisories/new

Or email ankurishwar88@gmail.com with "decisions.md security" in the subject.

Expect an acknowledgement within 7 days. If the report is valid, a fix and a
patched release will follow, and you will be credited in the release notes unless
you ask otherwise.

## Supported versions

Only the latest published version receives fixes.

| Version | Supported |
| :--- | :--- |
| latest `0.x` | yes |
| older | no |
